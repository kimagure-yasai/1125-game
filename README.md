# DOOM RUSH - 2.5D Time Attack Shooter

## 概要
**DOOM RUSH** は、初代DOOMのような2.5Dレイキャスティング表現を用いた、**タイムアタック × シューティング**のブラウザゲームです。  
外部ライブラリ・画像・音声ファイルを一切使用せず、単一のHTMLファイル（[game1.html](game1.html)、旧 `index.html`）を開くだけですぐにプレイできます。

スタート地点からコース奥にある緑の **EXITゲート** を目指して駆け抜けつつ、コース上の **敵（赤）** を倒してゴール時のタイムペナルティー（1体につき **+5.00秒**）を防ぎ、**的（ターゲット）** を撃ち抜いてスピードブーストを発動させながら最速タイムを目指します。

---

## 遊び方（操作方法）

1. [game1.html](game1.html) をWebブラウザで開きます。
2. 画面中央の **CLICK TO START** をクリックするとゲームが開始します。

### キー・マウス操作
| 操作 | 内容 |
| :--- | :--- |
| `W` `A` `S` `D`（または `↑` `↓`） | 前後・左右移動 |
| `Shift` | ダッシュ |
| マウス移動 / `←` `→` | 視点回転（画面クリックでPointer Lock有効） |
| 左クリック / `Space` | 射撃 |
| `R` | リスタート |
| `M` | 効果音 ON / OFF 切り替え |

### ルール
- **ゴール条件**: コース最奥の緑の `EXIT` ゲートに到達するとクリア。
- **ペナルティー**: ゴール時点で生き残っている **敵 1体につき +5.00秒** が走行タイムに加算されます。
- **スピードブースト**: コース上に設置された **的（水色・白・黄色の同心円ターゲット）** に弾を当てると一時的に移動速度が大幅にアップします。
- **ベスト記録**: 最終タイムのベスト記録はブラウザの `localStorage` に自動保存されます。

## 工夫した点

- **単一HTML完結・外部アセット不要の実装**
  - HTML5 Canvas 2D を用いた2.5Dレイキャスティングエンジンを自前で実装し、壁のテクスチャもコード内でプロシージャル生成しています。
  - 効果音（銃声・ヒット音・ターゲット命中音・撃破音・被弾音・回復音・ゴールファンファーレ）も Web Audio API でリアルタイム合成しています。
- **Zバッファと距離フォグによる立体感**
  - 壁の向き（縦面・横面）と距離に応じた暗さ表現に加え、Zバッファを用いたビルボード描画によって敵・的・弾・回復アイテム・EXITゲートの前後関係を正しく描画しています。
- **疾走感のあるブースト演出**
  - 的に当ててブーストが発動すると、移動速度の上昇（約1.48倍）に合わせて視野角（FOV）が少し広がり、画面周囲にスピード線（集中線）と `BOOST ACTIVE!` ゲージが表示されます。
- **ミニマップと快適な操作感**
  - 右上のミニマップで自分の位置・向き・敵（赤）・的（黄）・ゴール（緑）を把握でき、壁に沿ったスライド移動と水平方向のエイムアシストにより、走りながらでも快適に射撃できるようにしています。

## 作りながら変えた点

- **「敵」と「的（ターゲット）」の分離**（コミット `598e199`）
  - 開発初期は「敵に弾を当てると加速する」仕様で進めていましたが、「ペナルティーを避けるために倒すべき敵」と「加速のために狙って撃つ的」の役割を分けることで、レース中の判断とコース取りの面白さを強める方針に変更しました。
  - 結果として、赤い角付きの「敵」はペナルティー対象（かつ攻撃してくる障害）、水色・白・黄色の同心円の「的」は加速専用のターゲットとして実装されています。
- **ファイル名の整理**
  - 初期コミット（`598e199`）では `index.html` として作成・公開していましたが、その後ファイル構成の整理に伴い `game1.html` へリネームしました。
